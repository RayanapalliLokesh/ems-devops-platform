# Learning log

One page per phase, in your own words, written **before** the pull request is merged. The release notes of the
phase tag are a copy of this page, so the Releases page of the repository becomes the diary of the project.

File name: `phase-NN.md`. Keep it short:

```
# Phase NN - <topic>

## What I built
<3 to 5 lines>

## What went wrong and how I found it
<the command that showed the problem, the cause, the fix>

## What I would do differently
<1 or 2 lines>

## Evidence
<the command output or the link that proves it works>
```

An interviewer does not ask "did it work?". They ask "what broke?". This folder is where the answer comes from.
